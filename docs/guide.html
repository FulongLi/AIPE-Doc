AUTHORING GUIDE / 01
01 / GET STARTED

只需一份 HTML，就能开始。

选择合适的版式

文档：适合报告、笔记、教程和方案，以 A4 纵向输出。Slides：适合现场演讲和分享，以 16:9 横向输出。两种版式共用 Logo、颜色、表格、图注、提示框等组件；选择取决于阅读方式，而不是有没有视频。

复制与编辑

在 templates/ 目录内复制 document.html 或 slides.html，重命名后直接编辑。这样无需修改资源的相对路径；移动到其他目录时，需要一起调整 ../assets/ 等路径。

用代码编辑器修改 HTML：页面标题、作者、日期、版本、正文、图片说明和页脚。中英文都可使用；发布英文内容时，把根元素语言改成 lang="en"。模板不包含可视化编辑器。

打开与预览

直接双击 HTML 即可离线阅读，无需安装依赖。若已有 Node.js 18 或更新版本，在仓库根目录运行 npm run dev，打开 http://127.0.0.1:4173。运行 npm run check 检查本地链接与资源是否完整。

02 / COMPOSE YOUR CONTENT

可组合的内容模块

普通文字使用 p，章节用 h2 / h3，两栏使用 .two-col。需要强调的结论放进 .callout。复制现成模块并修改内容，即可保持一致的样式。

图片使用 figure、img 和 figcaption。写明 alt 替代文字、图号、条件与来源。优先用 SVG；位图需有足够分辨率，不要将小图强行拉伸。

表格保留 caption、thead 和带 scope 的表头。长表在浏览器打印中可重复表头；特别宽的表，应减少列数或拆分。

字体与品牌

官网配色与原始 Logo 已保存在本地。为了离线阅读，模板使用系统字体回退；不会请求在线字体。Logo 的原始比例保持不变。完整来源见仓库中的 assets/BRAND.md。

03 / PRINT TO PDF

让每一页，都保持清晰。

建议的打印设置

在桌面 Chrome / Edge 打开页面，点击“打印 / 存为 PDF”，或按 Ctrl + P。目标选择“另存为 PDF”，页面范围选择“全部”。

  1. 比例设为 100%（默认），避免额外缩放。
  2. 保留 CSS 默认纸张和边距。文档采用 A4 纵向，Slides 采用 254 × 142.875 mm 横向，即 16:9。
  3. 关闭浏览器“页眉和页脚”，避免网址和日期进入版心。
  4. 开启“背景图形”，保留黄色封面、提示框和表头底色。
  5. 检查右侧预览的页数、图表、页脚、链接和中文，再保存。

浏览器或系统打印驱动可能覆盖纸张设置。若 Slides 被强制放到 A4 上，优先使用 Chrome / Edge 内置“另存为 PDF”；确需纸张打印时，再选择适合纸张的缩放。

文档如何分页？

每个 .doc-page 是一个作者规划的页面区块，默认在下一页开始。复制一个区块即可新增页面，同时更新目录、页面 ID 与手写页码。

文档页不锁死高度，也不裁切内容。内容过多时会流到额外的打印页，作者页脚与页码不会自动在这些溢出页重复。发布前应拆分超长内容，重新核对手写页码。需要自动连续分页和重复页眉的长篇出版物，应另外采用专业分页引擎。

Slides 如何分页？

每个 .slide 是一张固定尺寸的幻灯片，打印时一张一页。屏幕窄时改为纵向阅读，打印仍保持 16:9。新增幻灯片时，更新页脚中的页码；播放控制栏会自动计算总页数。

一张幻灯片放不下时，应拆成两张。不要依赖隐藏溢出内容，也不要无限缩小字号。建议每页一个主要观点、三到五条重点，避免复杂表格。

PDF 保留的是阅读内容

网页导航、演示控制按钮会隐藏，视频会转换为封面。超链接在浏览器 PDF 中保留；请为重要链接提供文字地址。PDF 不保留视频播放或网页交互。

04 / MEDIA & SHARING

视频、演示，以及最后的分享。

添加视频

文档第三页包含视频插槽，默认显示明确的占位封面。将自己的 MP4 / WebM 放进 assets/；在 video 元素内添加或取消注释 source，并填好路径。脚本检测到来源后才显示播放器。

<source src="../assets/demo.mp4" type="video/mp4">

把屏幕与打印用的两张封面图，以及 video poster 一起替换。设置下方观看地址为稳定的 HTTPS 链接；离线本地视频路径无法供远端 PDF 读者访问。保留文字要点，涉及语音时添加真实字幕 track 与 WebVTT 文件。

Slides 同样可以复制该 figure 模块；请保持画面简洁并检查是否超出版心。外部 iframe 嵌入也应提供独立打印封面与链接，不能依靠 iframe 自己打印。

播放 Slides

点击“播放演示”进入逐页模式。支持左右方向键、上下方向键、Page Up / Page Down、Home / End，或使用底部按钮。按 Esc 或“退出”返回全部页面。浏览器允许时会进入全屏；拒绝全屏时仍可在网页内逐页播放。

演示过程中打印，仍会输出完整的所有幻灯片。较小屏幕使用纵向流式排版，优先保证内容可读；正式演讲建议使用桌面浏览器。

分享方式

离线：把 HTML 与 assets/ 按原目录关系一起打包，收件人解压后双击打开。单发一个 HTML 文件会丢失外部样式与图片。

在线：将仓库放到任意静态网站托管平台，例如 GitHub Pages。无需后端和构建，根目录的 index.html 即为入口；请保留各级相对路径。本仓库尚未配置或发布托管。

PDF：按上一页的设置导出后分享。若包含视频或互动内容，建议同时提供网页地址。

内容与授权

这套模板的说明文字与图示用于演示。品牌标识仍归原权利人所有，不因模板分享而转授商标权。对外分享前，请自行确定正文、图片、视频、数据的许可和分享范围。
