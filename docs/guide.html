AUTHORING GUIDE / 01
01 / GET STARTED

Start with a single HTML file.

Choose a format and language

Document: reports, notes and tutorials, printed in A4 portrait. Slides: talks and presentations, printed in 16:9 landscape. Both share the same brand styles and content modules, including video.

English is the default. Use document.html or slides.html for English; choose document.zh.html or slides.zh.html for Chinese. The language link opens the matching template. Each is a separate editable file; edits are not automatically translated or synchronised.

Copy and edit

Copy a template inside templates/, rename it and edit the HTML. Keeping it in that folder preserves relative asset paths. If you move it, update paths such as ../assets/.

Update the title, author, date, version, body, captions and footers. English files use lang="en"; Chinese files use lang="zh-CN". For a new document, update or remove its template language link so it points to your own translation.

Open and preview

Double-click any HTML file to read offline. No installation is required. With Node.js 18 or newer, run npm run dev and open http://127.0.0.1:4173. Run npm run check to check local links and assets.

02 / COMPOSE YOUR CONTENT

Combine content modules

Use p for paragraphs, h2 / h3 for headings, .two-col for columns, and .callout for a key finding. Copy existing modules to retain consistent formatting.

Use figure, img and figcaption for images. Include alternative text, conditions and sources. Prefer SVG or sufficiently detailed raster images. Keep table captions, thead and headers with scope; split tables that are too wide.

Fonts and branding

Original logos and brand colours are stored locally. System font fallbacks allow offline reading; no online fonts are requested. Logo proportions are preserved. Sources are listed in assets/BRAND.md.

03 / PRINT TO PDF

Keep every page clear.

Recommended print settings

Open the page in desktop Chrome / Edge. Click “Print / Save as PDF” or press Ctrl + P. Choose “Save as PDF” and include all pages.

  1. Use 100% scale to avoid additional resizing.
  2. Keep CSS default paper and margins: A4 portrait for documents and 254 × 142.875 mm landscape for 16:9 slides.
  3. Disable browser headers and footers to remove the URL and date.
  4. Enable background graphics to retain cover colours, callouts and table headings.
  5. Review page count, figures, footers and links before saving.

Some browsers or print drivers override page dimensions. Prefer the browser's built-in PDF destination. If printing onto physical paper, choose a suitable paper size and scale.

Document pagination

Each .doc-page is an authored page block that starts on a new printed page. Copy a block to add a page, then update the contents, IDs and manually written page numbers.

Document pages can grow instead of clipping content. Long content may continue onto extra pages, where the authored header and footer will not repeat automatically. Split long sections and check page numbers before sharing. For automatic running headers and continuous book pagination, use a dedicated pagination engine.

Slide pagination

Each .slide is a fixed-size slide with one PDF page. Small screens use a vertical reading layout; printing remains 16:9. Update footer page numbers when adding slides; presentation controls calculate the total automatically.

If a slide is too full, split it into two. Keep text readable and avoid hiding overflow. Aim for one main point and a few supporting details per slide.

PDF preserves reading content

Navigation and controls are hidden; videos become cover images. Links remain clickable in browser PDFs, but important links should also have readable URLs. Video playback and web interactions do not carry over into PDF.

04 / MEDIA & SHARING

Show, present and share.

Add a video

The document's third page includes a video slot with a labelled placeholder. Put your MP4 / WebM in assets/, then add or uncomment a source inside video with the correct path. The player appears only when a source is supplied.

<source src="../assets/demo.mp4" type="video/mp4">

Replace the screen and print cover images, plus the video poster. Add a stable HTTPS viewing link: a local file path will not work for remote PDF readers. Include a text explanation and, where speech conveys information, a real WebVTT captions track.

You can copy the same figure module into slides. Check that it fits. External iframe embeds also need a separate print cover and link.

Present slides

Click “Present” for one-slide-at-a-time mode. Use arrow keys, Page Up / Page Down, Home / End, or the controls. Press Esc or “Exit” to return to all slides. Fullscreen is requested when supported; presentation mode still works if it is declined.

Printing during presentation mode includes the full deck. Smaller screens use a vertical layout for readability. Use a desktop browser for a talk.

Share your work

Offline: package the HTML and assets/ together, preserving relative paths. Sending only an HTML file omits its external styles and images.

Online: use a static host such as GitHub Pages. No backend or build is required; root index.html is the default English entry, with index.zh.html as the Chinese option. Hosting has not been configured or published.

PDF: export using the previous page's settings. Also share the web URL if the content includes video or interaction.

Content and permissions

Template text and figures are illustrative. Logos remain the property of their owners. Confirm the permissions and audience for your text, media and data before sharing.
