A SIMPLE WORKFLOW

从记录，到分享。

不需要 Word 或 PowerPoint，也能做好一份内容。

01 /

选版式，复制一份

长内容选文档，现场讲解选 Slides。复制 HTML 文件，保留公共样式与素材目录。

02 /

写内容，自由组合

修改标题与正文，加入图片、表格或视频。所有模块使用同一套 AIPE 品牌样式。

03 /

发网页，或导出 PDF

静态托管后分享网址；也可以把整个文件夹发给对方。需要纸面版本时，直接打印为 PDF。

网页可展开，纸面也从容。

独立打印样式：隐藏操作栏、保留图文与链接，视频转换为封面与说明。建议使用桌面 Chrome / Edge 导出。
